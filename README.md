# スライム・キックオフ！ v0.06 LIVING WORLD

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.06 変更点
- スライムにまばたき、驚き顔、ランダムジャンプを追加
- 試合開始時にスライムが異次元ゲートから飛び出す演出を追加
- 中央ゲートに渦と光粒のアニメーションを追加
- 村長が試合中にランダムで応援するよう変更
- 押し込み成功時に村側の「うわっ、臭い！」演出を追加
- タッチボタンの pointerup / pointercancel を追加

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
