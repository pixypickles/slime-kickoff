# スライム・キックオフ！ v0.28 PLAIN GROWTH

## 今回の更新
- ぷれん村側を、白と黄色の花が咲く草原へ変更
- ぷれん村の初期能力「ぷれん」を追加
- ぷれんは属性を持たない代わりに、通常キックとノックバックが強め
- ぷれんの空中キックを「ホームランキック」に変更
- ホームランキックを受けた敵は壁まで飛び、約2秒張り付く
- 壁に張り付いた専用表示と復帰演出を追加
- ぷれんのスキル「気合い」を追加。短時間加速し、ダッシュを再使用可能にする
- 倒した村の技を習得する成長システムを追加
- 初期状態では「ぷれん」のみ使用可能
- ぶりふぉ村を倒すと氷技を解放
- さるびえ村を倒すと炎技を解放
- 解放状態はブラウザのlocalStorageへ保存
- 風と土は今後の村を倒すまでロック表示

3. さるびび村クリア予定：風技
4. たけぞ村クリア予定：土技
