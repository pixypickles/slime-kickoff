# スライム・キックオフ！ v0.05 VILLAGE

Godot・Unityを使わない、HTML / CSS / JavaScript製のスマホ向け試作ゲームです。

## 今回の更新

- v0.04 WORLDを土台として使用
- 左右の村に屋根、旗、応援する村人、荷車などを追加
- 村の入口を「スライムを押し付ける場所」として見やすく強調
- 村人キャラクターを、頭・胴体・大きな靴が読み取りやすい形に調整
- 頭は常に画面上向きのまま、靴だけが移動・キック方向を向く表現に変更
- スライムに顔、ぷるぷる、跳ね、微かな臭いの湯気を追加
- HUDを「押し付け数」「褒美まで」の世界観寄り表示に変更
- 村長と観客の応援演出を追加

## 今回は保留しているもの

スマホ用方向入力と4ボタン配置は、以前の修正が不十分だったため今回は触っていません。操作だけを独立して作り直す段階で対応します。

## 操作

PC: 矢印キー/WASD、Shift、J、K、L  
スマホ: 画面内の仮想スティックとボタン

`index.html` をブラウザで開くと起動します。
