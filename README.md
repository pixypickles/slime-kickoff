# スライム・キックオフ！ v0.12 HURRICANE

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.12 変更点
- 風の精霊スキルを「加速」から「ハリケーン」へ変更
- 小さな竜巻が向いている方向へ直進
- 近くの敵・味方・スライムを巻き込みながら運ぶ
- 竜巻の渦、風粒、吸い込み、スライムの驚き演出を追加
- ハリケーンのクールタイムを約7.2秒に設定
- 風の通常キックは、短い加速と強い吹き飛ばしを持つ「ウインドキック」のまま維持
- 高いジャンプ、空中キック、空中スキルの仕様を維持
- 画面下の能力説明とスキルボタン表記を更新

## 操作
- 移動：左の仮想スティック / WASD・矢印キー
- ダッシュ：画面ボタン / Shift
- キック：画面ボタン / J
- 大ジャンプ：画面ボタン / K
- 精霊スキル：画面ボタン / L

## 精霊能力
- 炎：ファイアボール＋ファイアキック
- 氷：コールドブレス＋アイスキック
- 風：ハリケーン＋ウインドキック
- 土：ロックキャノン＋強力なアースキック

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
