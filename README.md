# スライム・キックオフ！ v0.18 AIR KICK KNOCKOUT

## 今回の更新
- スライムが自発的にジャンプする頻度を増加
- 横方向へのジャンプ移動と、短い連続ジャンプを追加
- 空中ロックキャノンを斜め下へ叩き付ける軌道に変更
- 空中ファイアキックを「ロケットキック」に変更
- 蹴られた相手は下向きに火を噴射しながら上空へ消える
- 風の旋風脚を受けた相手も竹とんぼのように回転して上空へ消える
- 空中アイスキックは、相手を凍らせたまま横方向へ画面外まで滑らせる
- 炎・氷・風の空中キックを、一時退場技として統一
- 一時退場した相手は約3秒後、自陣入口から復帰
- アーススタンプの埋まり時間を約3秒へ延長
- 退場中の相手は追加攻撃や接触判定の対象外

## 操作
- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
