# スライム・キックオフ！ v0.11 HIGH JUMP & ELEMENT KICK

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.11 変更点
- ジャンプを大幅に高くし、人とスライムを軽く飛び越えられるように変更
- 空中でもキックと精霊スキルを使用可能
- 高く跳んでいる間は地上の接触判定と一部の飛び道具を回避
- 炎の通常キックを「ファイアキック」化。人を燃やし、スライムを熱で押し出す
- 氷の通常キックを「アイスキック」化。人とスライムを凍結
- 風の通常キックに追加吹き飛ばしと短い自己加速を付与
- 土の通常キックのノックバックと気絶を強化
- ダッシュジャンプ中のキックは、より強力なドロップキックになる

## 操作
- 移動：左の仮想スティック / WASD・矢印キー
- ダッシュ：画面ボタン / Shift
- キック：画面ボタン / J
- 大ジャンプ：画面ボタン / K
- 精霊スキル：画面ボタン / L

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。

## 設計メモ
今回はジャンプを残し、「空中からキックや魔法を出せる」方向を試しています。
将来スキルを2ボタンにする場合も、ジャンプを削除するのではなく、ダッシュ＋ボタンなどへ割り当てる案を比較できます。
