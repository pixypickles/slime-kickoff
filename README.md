# スライム・キックオフ！ v0.40

- 雲スライムを白基調へ調整
- 人と全スライムに高さ連動の影を追加（高いほど小さく薄い）
- 緑色の分裂スライムを追加
  - 時間経過または強い衝撃で2体に分裂
  - 2体とも同じゴールに入った場合のみ得点
  - 別々のゴールに入った場合は得点なしで中央へ復帰
  - 分裂中、気まぐれに1体へ戻る
