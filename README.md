# スライム・キックオフ！ v0.09 WIND SPIRIT

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.09 変更点
- 細長い画面・折りたたみスマホでスタートボタンが隠れる問題を修正
- 導入画面を画面内スクロール式に変更
- 準備表示とスタートボタンを画面下部へ固定表示
- 高さが極端に低い画面では物語の一部を自動的に省略
- 「風の精霊使い」を追加
- 風スキル「加速」を追加（短いクールタイム約2.4秒）
- 加速中の風の軌跡と専用クールタイム表示を追加

## 操作
- 移動：左の仮想スティック / WASD・矢印キー
- ダッシュ：画面ボタン / Shift
- キック：画面ボタン / J
- ジャンプ：画面ボタン / K
- 精霊魔法：画面ボタン / L

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
