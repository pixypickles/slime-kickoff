# スライム・キックオフ！ v0.31 CHESTAPI LIGHTNING

## 修正
- スライム種類とステージ進行を完全に分離
- 「よく跳ねるスライム」を選んでもステージ順が飛ばないよう修正
- 進行順を ぶりふぉ → さるびえ → さるびび → たけぞ → ちぇすたぴ に固定

## 新ステージ
- 5つ目の対戦相手「ちぇすたぴサーカス団」を追加
- 濃いネイビーのユニフォーム
- サーカステント、電飾、スポットライト、雷色ゲートを追加
- 相手CPUは雷属性を使用

## 雷属性
- Aボタン／スキル：ライトニングダッシュ
- スライム方向へ人約2人分を高速移動
- 移動中に触れた人とスライムを感電
- 地上サンダーキックも触れた対象を感電
- 空中キックは「落雷急降下キック」
- 周囲の対象を約3秒、煙を出す行動不能状態にする
- 感電の稲妻とプスプス煙の表示を追加
- ちぇすたぴ撃破で雷技を解放

`index.html` をブラウザで開いてください。スマホは横画面推奨です。
