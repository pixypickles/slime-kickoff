# スライム・キックオフ！ v0.17 GROUND IMPACT & AI

## 今回の更新
- 蹴られた人が浮くノックアップを廃止
- 人への横方向ノックバックをさらに強化
- スライムだけは軽く浮きやすい挙動を維持
- CPUが一人のプレイヤーを100%追い続けないよう行動AIを変更
- CPUは「スライム追跡・守備・先回り・短時間の妨害」を定期的に切り替える
- 妨害行動の割合と攻撃頻度を低下
- 土属性の空中キックを「アーススタンプ」に変更
- アーススタンプを受けた相手は約1.35秒、地面に埋まり靴だけが見える
- 埋まる際に土煙と画面揺れを追加
- 風属性の空中キック「旋風脚」の回転軸を修正
- 全身が側転する表示をやめ、頭から足を軸に蹴り足が竹とんぼ状に回転
- 水平な二重風リングを追加

- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L
