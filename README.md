# スライム・キックオフ！ v0.08 ICE SPIRIT

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.08 変更点
- 試合前に「炎」と「氷」の精霊を選択可能
- 氷の精霊使いと専用の髪・ゲージ表示を追加
- コールドブレスを追加（狭い扇形、クールタイム約6.4秒）
- 範囲内の敵とスライムを凍結
- 凍ったスライムは触れたり蹴ったりすると大きく滑る
- 敵チームの先頭キャラは、プレイヤーと反対属性を使用
- 冷気の扇形エフェクト、氷粒、凍結表示を追加

## 操作
- 移動：左の仮想スティック / WASD・矢印キー
- ダッシュ：画面ボタン / Shift
- キック：画面ボタン / J
- ジャンプ：画面ボタン / K
- 精霊魔法：画面ボタン / L

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
