# スライム・キックオフ！ v0.04 WORLD

Godot・Unityを使わない、HTML / CSS / JavaScript製のスマホ向け試作ゲームです。

## 今回の更新

- v0.02を土台として使用（入力修正版は不採用）
- 導入ストーリーを世界設定に合わせて再構成
- 横長の楕円形コートを「異次元に削り取られた土地」として描き直し
- 左右に二つの村、壊れた塀、村へ続く入口を追加
- コート中央に小さな異次元ゲートを追加
- 土壁を不規則な輪郭と石で表現
- ロード中メッセージを世界観に合わせて変更
- 試合開始・村長の台詞を「押し付け合い」らしく変更

## 操作

現段階では v0.02 の操作を維持しています。入力配置とキャラクターの向きは、世界観の土台が整った後に改めて修正します。

PC: 矢印キー/WASD、Shift、J、K、L  
スマホ: 画面内の仮想スティックとボタン

`index.html` をブラウザで開くと起動します。
