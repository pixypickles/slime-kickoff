# スライム・キックオフ！ v0.56

## 追加：さるびえ村村長
ちぇすたぴサーカス団クリア後の「村長参戦モード」で、参戦する村長を選択できます。

### さるびえ村村長の操作
- Aボタン：拡散ファイアボール（前方5方向）
- 通常キック：キックと同時に直進ファイアボール
- 空中キック：退場キックに加え、下方向へ3発の下降ファイアボール
- ダッシュボタン：熱風（自陣側から相手陣地へ進み、敵とスライムを押し流す）
- 通常ダッシュ：なし
- ジャンプ：村長共通の高いジャンプとゆっくりした降下

ぶりふぉ村村長の能力は変更していません。

## v0.57 CHIEF VS CHIEF
- ぶりふぉ村村長の空中氷弾を、真下・斜め前下・斜め後ろ下の3方向に統一。
- 村長の空中キック接触は退場技ではなく、ぶりふぉ村長は4秒凍結、さるびえ村長はその場で燃えてゴロゴロ消火する状態異常へ変更。
- 村長参戦モードで対戦相手の代表を「通常リーダー／ぶりふぉ村村長／さるびえ村村長」から選択可能。
