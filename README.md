# スライム・キックオフ！ v0.07 FIRE SPIRIT

ブラウザで動く、3対3のスライム押し付けアクション試作版です。

## v0.07 変更点
- 両チームの先頭キャラクターを「炎の精霊使い」に変更
- スキルボタンでファイアボールを発射（クールタイム約5秒）
- ファイアボールが人に当たると、燃えてコロコロ転がりながら消火
- スライムに当たると、命中方向へ大きく転がる
- 火球の光、尾、火の粉、着弾エフェクトを追加
- 炎の精霊使いの髪とスキルゲージを専用表示に変更
- CPUの炎使いも状況に応じてファイアボールを使用

## 操作
- 移動：左の仮想スティック / WASD・矢印キー
- ダッシュ：画面ボタン / Shift
- キック：画面ボタン / J
- ジャンプ：画面ボタン / K
- 炎魔法：画面ボタン / L

## 起動方法
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
