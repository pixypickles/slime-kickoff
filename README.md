## 修正内容

- 村長参戦モードで、操作側に「たけぞ村村長」を選んだ際、左側の村・コートがぷれん村の見た目になる問題を修正しました。

- 村長戦では左右それぞれ、選択した村長に対応する村名・旗・地面・コート配色・観客色を表示します。
