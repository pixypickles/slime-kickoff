# スライム・キックオフ！ v0.19 AIR SLIME VOLLEY

## 今回の更新
- 地上のスライムへ空中キックを当てた場合は、地上キックと同じ属性効果
- ジャンプ中のスライムへ空中キックを当てると「空中ボレー」
- 空中ボレー中は属性効果をレジストし、蹴った側の相手ゴールへ高速で飛ぶ
- ボレー中のスライムは高速回転し、専用の軌跡を表示
- 空中のスライムは、空中キックや各種スキルで迎撃可能
- スライムの自発ジャンプ頻度をさらに増加
- 横方向へのジャンプ移動を優先
- 低重力寄りの、長くふわっとした滞空へ調整
- ときどき短い間隔で連続ジャンプ
- 空中ボレー後もしばらく回転が残る

## 操作
- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
