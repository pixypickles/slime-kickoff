# スライム押し付け合戦 v0.01

ブラウザだけで動く、3対3のスマホ向け試作版です。Godot・Unityは不要です。

## 遊び方

- 左下の仮想スティック：移動
- ダッシュ：2～3歩だけ加速
- キック：スライムや相手選手を吹き飛ばす
- ジャンプ：ジャンプ中にもキック可能
- スキル：味方側は時間停止、敵側は全員気絶
- ダッシュ中キック：スライディング
- ダッシュ＋ジャンプ＋キック：強力なドロップキック

スライムを相手側（右）の村へ3回押し込むと勝利です。

## PC操作

- 移動：矢印キー / WASD
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

## GitHub Pages

このフォルダをGitHubリポジトリへアップロードし、Settings → Pages → Deploy from a branch を選ぶと公開できます。
