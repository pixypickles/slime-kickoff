# スライム・キックオフ！ v0.20 RESULTS & STAGES

## 今回の更新
- 旋風脚で退場する相手の回転を修正
- 頭から足までを一本の軸にし、竹とんぼのように高速回転
- 試合終了画面に「再戦」「メニューへ戻る」「次のステージ」を追加
- 勝利時のみ次のステージボタンを表示
- メニュー画面でスライム種類を選択可能
- 「ノーマル」と「よく跳ねるスライム」を追加
- よく跳ねるスライムは、自発ジャンプ・横移動・連続ジャンプが強め
- 次のステージでは「よく跳ねるスライム」が自動選択される
- 将来の村・属性ステージ進行に対応しやすい状態へ整理

## 将来構想
最初の村を氷の種族、対戦相手を炎の村などに設定し、クリア後に
「新たな異次元空間が発生！ 別の村と繋がった！」
という形で、風・土などの村へ進む構成を想定しています。

## 操作
- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
