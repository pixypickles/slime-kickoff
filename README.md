# スライム・キックオフ！ v0.02

ボールの代わりに、少し臭いスライムを相手の村へ押し込む3対3のブラウザ対戦アクションです。
Godot・Unityは使わず、HTML / CSS / JavaScriptのみで動作します。

## v0.02 更新内容

- 世界観を読めるロード兼イントロ画面を追加
- 読み込みメッセージを順番に表示
- コートを横長の楕円形へ変更
- 周囲を土壁、左右を村の入口として表現
- 村人を頭・胴体・大きな靴の見た目へ変更
- キック時に前側の靴が大きく伸びる演出を追加
- スライムの自発ジャンプを追加
- 両村の村長と応援メッセージを追加

## 遊び方

`index.html` をブラウザで開いてください。

### PC操作

- 移動: WASD / 矢印キー
- ダッシュ: Shift
- キック: J
- ジャンプ: K
- スキル: L

### スマホ操作

画面左の仮想スティックと、画面右の4ボタンを使用します。

## GitHub Pages

リポジトリ直下にファイルを置き、Settings → Pages から公開できます。
