# スライム・キックオフ！ v0.15 IMPACT & MOBILITY

## 今回の更新
- 靴は片足を胴体の下に固定
- もう片方の靴はキック時だけ大きく前へ振り出す
- 通常キック、空中キック、ダッシュキック、ドロップキックのノックバックを強化
- 炎・氷・風・土の属性効果を、空中キックとダッシュキックにも適用
- 敵同士の接触時に反発力を加え、密着し続けにくく調整
- ダッシュを「短距離・高速・短クールタイム」に変更
- ジャンプを高く、短い入力でも発動しやすいテンポへ調整
- 空中ファイアボールに高度を追加
- ファイアボールはゆっくり下降し、スライムか近い敵へ追尾
- ファイアボールの寿命、衝突判定、吹き飛ばしを強化

## 操作
- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
