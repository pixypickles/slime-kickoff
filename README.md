# スライム・キックオフ！ v0.28.2 WALL STICK FIX

## 修正内容
- ホームランキック後、壁に張り付いた相手が解除されない不具合を修正
- 原因は、壁張り付きの描画処理が誤って `Player.update()` 内に入り、タイマー更新より先に `return` していたこと
- 描画処理を `Player.draw()` へ戻し、更新処理ではタイマーだけ進むよう修正
- 約2秒後に必ず張り付き状態を解除
- 解除時にキャラクターを壁の内側へ少し戻し、中央方向へ押し出すよう調整
- メニューへ戻った際の開始ボタン修正も維持

`index.html` をブラウザで開いてください。
