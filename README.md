- コートそのものを中央から半分ずつ、両村の景色に変更
- 左半分は常に「ぷれん村」の土、花、素朴な景色
- 右半分は対戦相手の村の景色

- さるびえ村クリア後に「次の接続先：さるびび村（準備中）」を表示
