# スライム・キックオフ！ v0.14 CHARACTER & AUTO AIM

## 今回の変更
- 操作キャラクターの両足・両靴を胴体の真下へ固定
- 移動方向によって靴が頭側へ回り込む表示を廃止
- キック時は靴の位置を崩さず、向いている方向へ衝撃線を表示
- ファイアボールの当たり判定と見た目を約1.5倍に拡大
- 全精霊スキルに自動照準を追加
- 基本はスライムまたは最も近い敵を狙い、密着した敵を優先
- スキル発動時にキャラクターの向きも対象方向へ更新
- コールドブレスの根元にあった当たり判定の空白を削除
- 密着している人やスライムは発動直後に凍結するよう修正
- 空中スキルと既存の世界観・ハリケーン仕様を維持

## 起動
`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
