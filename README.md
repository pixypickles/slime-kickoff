# スライム・キックオフ！ v0.16 AIRBORNE & WIND SPIN

## 今回の更新
- 蹴られた人が少し浮くノックアップを追加
- スライムの滞空時間と高さを増やし、重力を少し弱く見せる調整
- 人が左右の村入口まで吹き飛ばされた場合、約1.15秒後に復帰
- 復帰地点で短い再登場エフェクトを表示
- 風属性の空中キックを「旋風脚」に変更
- 旋風脚中はフィギュアスケートのように全身が回転
- 回転中に二重の風リングを表示
- ファイアボールや強い攻撃で、人とスライムが少し浮きやすく調整
- 復帰待ちのキャラクターは接触判定から除外

## 操作
- 移動：仮想スティック / WASD・矢印キー
- ダッシュ：Shift
- キック：J
- ジャンプ：K
- スキル：L

`index.html` をブラウザで開いてください。スマホでは横画面推奨です。
